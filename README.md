# Blog-Post-Java-Full-Stack
In this repository i have make blog post application of java 
🚀 **Tech Stack**

Backend: Java, Spring Boot

Frontend: Thymeleaf, HTML, CSS, Bootstrap

Database: MySQL

ORM: Spring Data JPA

Architecture: MVC Pattern

✨ **Features**

Create new blog posts

View all blog posts

Update existing posts

Delete blog posts

Publish date selection using date picker

Server-side rendering with Thymeleaf

MySQL database integration

🧠 **What I Learned**

How Spring Boot handles HTTP requests

Dependency Injection in Spring

JPA entity mapping with MySQL

Connecting frontend forms to backend using th:field

Implementing MVC architecture properly

Handling CRUD operations end-to-end

🗂 **Project Structure**

Controller Layer – Handles HTTP requests

Service Layer – Business logic (if implemented)

Repository Layer – Database interaction using JPA

Entity Layer – Database table mapping

Templates Folder – Thymeleaf HTML files

🛠 **Setup Instructions**

Clone the repository

Configure MySQL database in application.properties

spring.datasource.url=jdbc:mysql://localhost:3306/blogdb
spring.datasource.username=your_username
spring.datasource.password=your_password

Run the Spring Boot application

**Open browser at:**

http://localhost:8080
